# AURENZA BROKER Brand System

## Primary identity

**AURENZA BROKER**

Tagline: **Smart Trading. Secure Future.**

## Locked palette

| Role | Color | Hex |
|---|---|---|
| Deep Green | Primary brand | `#2A402D` |
| Cream | Main background | `#FAF9F6` |
| Gold | Premium accent | `#C9A063` |
| Green | Positive/success | `#4CAF50` |
| Red | Error/danger | `#8B0000` |
| Dark Navy | Dark UI support | `#0B192B` |
| Beige | Soft surface | `#E2D6BD` |

## Usage

- Primary interface: Cream + Deep Green + Gold.
- Dark/private screens: Dark Navy + Deep Green + Cream + Gold.
- Positive trading/health states: Green.
- Destructive/error states: controlled Red.
- Avoid replacing the palette with generic fintech blue/black.

## Logo direction

Use the AURENZA symbol as the primary app mark and AURENZA BROKER as the wordmark. The symbol should communicate protection, markets, movement and growth without relying on a generic dollar sign or copied candlestick logo.

## Product naming

User-facing product name is **AURENZA BROKER**. Short brand is **AURENZA**. Existing database/table/function identifiers containing the former internal project name should not be renamed casually because that could break deployed migrations; those identifiers are implementation names, not the customer-facing brand.
